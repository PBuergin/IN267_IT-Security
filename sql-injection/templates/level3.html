Lizenz-Prüfungs API (Intern)

Bitte geben Sie den Lizenzschlüssel der Faust Electronics GmbH ein, um die Software zu aktivieren.

API Dokumentation für Entwickler:

GET /level3/api/check-license?key={LIZENZ_SCHLUESSEL}
Response: {"status": "success" | "error", "message": "..."}
